Status: in progress

This checkpoint establishes the first reviewed slice of the V4 capability
contract. It does not claim that G3, the first business capability, or the
release is complete.

## Included

- A versioned, data-only capability registry with stable capability IDs.
- The fixed V1 discovery and invocation command surface.
- One reviewed read capability: `account.account.list`.
- Draft 2020-12 request, response, and registry schemas enforced at runtime.
- A single-document JSON stdout contract and stable exit-code mapping.
- Company-scoped, database/user-bound cursor semantics.
- A registry-driven Pi Skill packaged with the wheel.
- A public-safe summary of the reviewed initial CLI-Anything generation
  checkpoint. The byte-exact raw baseline remains server-local for provenance
  and refinement because it contains environment-specific paths.

The remaining fixed write and operation commands are present as explicit
unavailable command shells. They do not perform writes.
