Status: in progress

This checkpoint establishes the reviewed V4 capability contract and records
the current planned-capability baseline. It does not claim that the baseline is
the final complete matrix, that G3 is complete, or that the release is complete.

## Crosswalk calibration

The subsequent command-surface and semantic crosswalk does not treat the 102-ID
baseline as a proven final count. Its reviewed minimum currently identifies two
required capability IDs that are not yet registered (`asset.depreciation.post`
and `bank.statement.import`), 52 existing IDs whose closed business contracts
need expansion, and nine product-boundary decision packages. Those additions,
contract changes, and decisions must be frozen and reviewed before G3 can pass;
they are not silently represented by the current generic or similarly named
descriptors.
- Company-scoped, database/user-bound cursor semantics.
- A registry-driven Pi Skill packaged with the wheel.
- A public-safe summary of the reviewed initial CLI-Anything generation
  checkpoint. The byte-exact raw baseline is retained outside the public Git
  tree for provenance and refinement because it contains environment-specific
  paths.

The remaining fixed write and operation commands are present as explicit
unavailable command shells. They do not perform writes.

## Deliberate limitations

- The twenty-five public descriptors remain `unconfigured`, not globally
  `available`. G5 has validated their real bridges in the two private synthetic
  environments; availability remains a runtime database/company/user decision.
- The remaining implementations and specialized schemas, and the write state
  machine remain pending; matrix registration alone does not make a capability
  callable.
- Branch coverage is currently 75%; the final G8 threshold remains 85%.
- The initial generator baseline is retained for provenance and refinement; it
  is not the authoritative runtime implementation.

No existing database, Odoo service, Odoo source tree, V2/V3 installation, or
legacy harness was modified by this checkpoint.
