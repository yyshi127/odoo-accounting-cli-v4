  environments, while availability remains a runtime database/company/user
  decision.
- `currency.rate.record` remains disabled. A rollback-only live probe confirmed
  that `res.currency.rate` creation requires the accounting-manager role while
  the configured uid 5 is an ordinary accountant; no ACL bypass, `sudo`, or
  user-group mutation was used to make the command appear available.
- `budget.line.list` and `budget.line.get` return computed amounts that Odoo
  obtains through `budget.report`. The standard Odoo ACL is sufficient and the
  real dual-database calls pass, but the preflight model metadata does not yet
  declare that indirect dependency. A deployment with custom `budget.report`
  ACLs may therefore fail at runtime instead of preflight; this control-plane
  refinement is deliberately deferred.
- The remaining implementations, specialized schemas, and consolidated
  later-phase write controls remain pending; matrix registration alone does not
  make a capability callable.
- Branch coverage is currently 75%; the final G8 threshold remains 85%.
- The initial generator baseline is retained for provenance and refinement; it
  is not the authoritative runtime implementation.
