# Public execution goal summary

Build and deliver an independent Odoo Accounting CLI V4 against Odoo 19 using the fixed CLI-Anything v0.4.0 generator source. Delivery requires real ORM, wizard and report integration; stable JSON contracts; capability discovery; safe write preview, approval, idempotency, audit and verification; automated and Pi end-to-end tests; offline installation, upgrade and rollback; and a reproducible public release.

Only two newly created synthetic V4 databases may receive automated writes. All pre-existing databases, Odoo services and source trees, previous CLI versions and legacy harnesses remain protected.

This public repository contains only independently authored V4 code, public contracts and sanitized documentation. It excludes Odoo Enterprise/custom source, private environment evidence, raw generation transcripts, credentials and real business data.
